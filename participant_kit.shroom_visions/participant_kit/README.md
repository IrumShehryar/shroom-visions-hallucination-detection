# SHROOM-Visions participant kit

This archive contains the participant kit for the SHROOM-Visions shared task.

It contains the following four items:
1. a copy of the scoring program (`scorer.py`), for reference
2. a format checker (`format_checker.py`) that can verify that submitted files match the submission platform's expectations,
3. two baselines systems: a naive constant prediction baseline (`baselines/constant_baselines.py`) and a baseline inspired from [Hallushift++](https://arxiv.org/abs/2512.07687) (`baselines/hallushift++/baseline.ipynb`). Further information for this latter system is provided in a separate file (see `baselines/hallushift++/README.md`).

All software is provided as-is and meant mostly for documentation purposes.
